# Code of Conduct

## Our pledge

We want participation in Rivet to be a harassment-free experience for everyone,
regardless of age, body size, disability, ethnicity, sex characteristics, gender
identity and expression, level of experience, education, socio-economic status,
nationality, personal appearance, race, religion, or sexual identity and
orientation.

## Expected behavior

- Be direct about technical problems and generous about people.
- Assume good faith; ask for the reproduction instead of assigning motive.
- Respect that this repository owns framework contracts, not another
  maintainer's product, commercial terms, or platform account.
- Do not publish another person's credentials, private paths, customer data, or
  security report.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, sustained disruption,
sexualized attention, and publishing private information without permission are
not acceptable in issues, pull requests, discussions, or any project space.

## Scope

This code applies in repository spaces and when representing the project
elsewhere.

## Reporting and enforcement

Report conduct concerns privately to the repository owner
[@turlamai](https://github.com/turlamai). Reports are reviewed promptly and kept
confidential. Maintainers may warn, remove content, or temporarily or permanently
ban participation. Security vulnerabilities follow [SECURITY.md](SECURITY.md),
not this process.
